# AlgoTradeX Indian Market Strategies – Detailed Specs For 20 Families

Generated by Perplexity

## Overview

This report gives concrete, implementation‑ready specifications for **20 strategy families** designed for the AlgoTradeX Slice‑1 runtime on Indian markets (NSE/BSE/NFO).[^1][^2]

Each strategy is described in a uniform template so it can be translated directly into a `StrategyProvider` plus `TradeSignalStrategy` or `TradeIntentStrategy` implementation:

- SPI choice (signal‑only vs lifecycle‑aware) and suggested `strategyId`.
- Primary instruments and timeframes (indices, F&O stocks; 5–15‑minute, H1, D).
- Key parameters (exposed via `StrategyParameterSchema`).
- Closed‑bar **setup, trigger, invalidation** rules.
- Exit and risk logic expressed in AlgoTradeX’s TradeIntent vocabulary where relevant.[^1]
- India‑specific microstructure rules (session buckets, expiry days, STT/brokerage drag, circuit behavior) encoded as filters or notes.[^2]

All designs respect the Slice‑1 SPI constraints: no tick or Level‑2 data, no options chain or Greeks, no multi‑instrument coordination in one strategy instance, and no custom indicator SPI.[^2][^1]

## 1. Trend Rider India – EMA Stack Trend Strategy

**Id:** `trend-rider-india-v1`  
**SPI:** `TradeIntentStrategy`.[^2]

### SPI, Instruments, Timeframes

- Timeframes: `M15` and `H1` as primary; optional `D` for higher‑TF bias.
- Instruments: BANKNIFTY futures (M15), NIFTY futures (H1), large‑cap F&O stocks (D).[^2]
- Capabilities: `LONGSIGNALS`, `SHORTSIGNALS`, `TRADEINTENT`, `LONGENTRYINTENT`, `SHORTENTRYINTENT`, `EXITINTENT`, `SCALEININTENT`, `RISKAWARESIZING`, `PORTFOLIOAWARE`.[^2]

Key parameters (subset):

- `fastEmaPeriod INTEGER` default 20; `slowEmaPeriod INTEGER` default 50; `trendEmaPeriod INTEGER` default 200.
- `higherTfBias ENUM` {`H1`,`D`} default `H1`.
- `minAdx DECIMAL` default 20.
- `initialStopAtr DECIMAL` default 1.5; `trailStopAtr DECIMAL` default 2.5.
- `riskFraction DECIMAL` default 0.005 (0.5%).
- `maxHoldingBars INTEGER` default 80; `cooldownBars INTEGER` default 4.[^2]

### Setup, Trigger, Invalidation

**Setup (trend filter):**

- Primary‑TF close above `trendEMA` for LONG, below for SHORT.
- `fastEMA > slowEMA` (LONG) or `<` (SHORT).
- `MarketContextSnapshot.trendStrength` in {`MODERATE`,`STRONG`} and `PrimaryMarketRegime` not `RANGINGLOWVOLATILITY`/`CHOPPY`.[^1][^2]
- Higher‑TF (`H1` or `D`) context trend direction aligned with trade side.

**Trigger (pullback entry):**

- Price pulls back to within 0.3 ATR of `fastEMA` (or `slowEMA` if configured) and then closes back in trend direction (bullish candle for LONG, bearish for SHORT).

**Invalidation:**

- Primary‑TF close beyond `slowEMA` against trade direction.
- `MarketContext.marketStructure` flips to `CHOPPY` for ≥3 consecutive bars.
- `barsHeld` exceeds `maxHoldingBars`.

### Exit And Risk

- Initial stop: below recent swing low minus `initialStopAtr * ATR` for LONG; above swing high for SHORT.
- Trailing: After first scale‑out, apply ATR trail at `trailStopAtr * ATR`.
- Optional SCALEIN on subsequent pullbacks that meet setup, capped at 1–2 additional units; reject if 3‑5‑7 risk budget would be breached using `portfolioState`.[^2]

### India‑Specific Notes

- Skip entries in opening 15 minutes (9:15–9:30) and final 30 minutes (14:45–15:15) to avoid auction‑driven and close‑out noise.[^3][^2]
- Disable new entries on or near weekly/monthly expiry for index futures; treat expiry dates as configured parameters.[^2]

## 2. SMA/EMA Crossover Core For NSE

**Id:** `india-sma-ema-crossover-core-v1`  
**SPI:** `TradeSignalStrategy`.[^1]

### SPI, Instruments, Timeframes

- Timeframes: `M5`, `M15`, `H1`, `D`.
- Instruments: NIFTY, BANKNIFTY futures; liquid index ETFs; large‑cap stocks.
- Capabilities: `LONGSIGNALS`, `SHORTSIGNALS`.

Key parameters:

- `maType ENUM` {`SMA`,`EMA`} default `EMA`.
- `fastPeriod INTEGER` default 9; `slowPeriod INTEGER` default 21.
- `minAdx DECIMAL` default 20.
- `allowShorts BOOLEAN` default true.
- `cooldownBars INTEGER` default 3.

### Setup, Trigger, Invalidation

**Setup:**

- Compute fast/slow MA; compute ADX from MarketContext component metrics.[^1]
- Require ADX ≥ `minAdx` and regime not `RANGINGLOWVOLATILITY`.[^2]

**Trigger:**

- LONG signal when fast MA crosses above slow MA; SHORT when it crosses below.
- Optionally require price above/below 200‑period MA for trend confirmation.

**Invalidation:**

- Cooldown: After a cross, suppress further signals for `cooldownBars` to avoid whipsaws.

### India‑Specific Notes

- Heavier whipsaws around opening and during low‑volume midday; parameter presets should be different for BANKNIFTY M5 vs NIFTY D.[^4][^5]

## 3. Range Breakout India – Rolling/Opening Range Breakouts

**Id:** `range-breakout-india-v1`  
**SPI:** `TradeIntentStrategy`.[^2]

### SPI, Instruments, Timeframes

- Timeframes: `M15` and `H1`.
- Instruments: BANKNIFTY, NIFTY futures.

Key parameters (subset):

- `rangeLookbackBars INTEGER` default 20.
- `useOpeningRange BOOLEAN` default true.
- `openingRangeMinutes INTEGER` default 15.
- `breakoutBufferPct DECIMAL` default 0.10.
- `volumeExpansionMultiple DECIMAL` default 1.5.
- `atrExpansionMultiple DECIMAL` default 1.2.
- `targetRR DECIMAL` default 2.5.
- `initialStopAtr DECIMAL` default 1.0.

### Setup, Trigger, Invalidation

**Setup:**

- If `useOpeningRange`, define range high/low using first `openingRangeMinutes` from 9:15; else use rolling `rangeLookbackBars` highs/lows.[^6][^7]

**Trigger:**

- LONG when close breaks above range high by `breakoutBufferPct` and volume ≥ `volumeExpansionMultiple * avgVolume20` and ATR ≥ `atrExpansionMultiple * avgAtr20`.
- SHORT mirror below range low.

**Invalidation:**

- If price re‑enters range within 2 bars of breakout, mark as false breakout and exit at market; suppress new trades for `cooldownBars`.

### Exit And Risk

- Stop: `initialStopAtr * ATR` away from entry, but never inside original range.
- Target: R‑multiple target at `targetRR`; optional partials at 1R.
- Time stop: Exit if not in profit after 8 bars.

### India‑Specific Notes

- Avoid trades on weekly/monthly expiry days (options‑dominated microstructure causes fakeouts).[^8][^2]

## 4. Range Fade India – Mean‑Reversion In Ranges

**Id:** `range-fade-india-v1`  
**SPI:** `TradeIntentStrategy`.[^2]

### SPI, Instruments, Timeframes

- Timeframes: `M15`, `H1`.
- Instruments: NIFTY, BANKNIFTY, large‑cap stocks.

Key parameters:

- `rangeLookbackBars INTEGER` default 30.
- `rangeQualityMaxAdx DECIMAL` default 20.
- `rsiPeriod INTEGER` default 14.
- `rsiOversold DECIMAL` default 30; `rsiOverbought DECIMAL` default 70.
- `bandTouchTolerancePct DECIMAL` default 0.15.
- `maxHoldingBars INTEGER` default 20.

### Setup, Trigger, Invalidation

**Setup:**

- ADX below `rangeQualityMaxAdx` and `marketStructure` = `RANGEBOUND` from MarketContext.[^1][^2]
- Identify rolling high/low as range boundaries.

**Trigger:**

- LONG when price touches or slightly pierces range low (within `bandTouchTolerancePct`), RSI ≤ `rsiOversold`, and bar closes bullish.
- SHORT mirror at range high with RSI ≥ `rsiOverbought`.

**Invalidation:**

- Range break: close beyond boundary plus tolerance.
- Three consecutive closes near boundary without bounce (indicates potential breakout).

### Exit And Risk

- Target: Midpoint of range or configurable fraction (for example 0.7 of range distance).
- Stop: Slightly beyond range boundary plus `0.8 * ATR`.
- Time stop: Exit after `maxHoldingBars`.

### India‑Specific Notes

- Restrict trades to 9:45–14:15 to exploit midday mean‑reversion behavior documented for Indian indices.[^3][^2]

## 5. Momentum Ride India – Short‑Term Momentum Bursts

**Id:** `momentum-ride-india-v1`  
**SPI:** `TradeIntentStrategy`.[^2]

### SPI, Instruments, Timeframes

- Timeframes: `M5`, `M15`.
- Instruments: BANKNIFTY, NIFTY futures; highly liquid stocks.

Key parameters:

- `rocLookbackBars INTEGER` default 12.
- `rocLongThresholdPct DECIMAL` default 1.5; `rocShortThresholdPct DECIMAL` default −1.5.
- `macdConfirmation BOOLEAN` default true.
- `rsiNotOverboughtMax DECIMAL` default 78; `rsiNotOversoldMin DECIMAL` default 22.
- `volumePulseMultiple DECIMAL` default 1.8.
- `maxHoldingBars INTEGER` default 12.

### Setup, Trigger, Invalidation

**Setup:**

- ROC over `rocLookbackBars` exceeds respective threshold.
- Volume ≥ `volumePulseMultiple * avgVolume20`.
- MACD line > signal (LONG) or < (SHORT) when `macdConfirmation` enabled.[^9][^1]

**Trigger:**

- Entry bar is first bar satisfying all setup conditions; entry at market‑next‑open.

**Invalidation:**

- For long, RSI falls back below 50 with two consecutive lower closes; mirror for short.

### Exit And Risk

- Tight ATR stop (for example 1.2 * ATR) to respect high whipsaw rate.
- Time stop at `maxHoldingBars`.
- Optional pyramid once price makes new high/low with continued volume spike, capped by risk limits.

### India‑Specific Notes

- Best windows: gap days at open and power hour 14:30–15:15; avoid midday unless strong ROC/volume persists.[^8][^3]

## 6. Exhaustion Reversal India – Oscillator + Structure Reversals

**Id:** `exhaustion-reversal-india-v1`  
**SPI:** `TradeIntentStrategy`.[^2]

### SPI, Instruments, Timeframes

- Timeframes: `M15`, `H1`.
- Instruments: Indices and large‑cap stocks.

Key parameters:

- `rsiPeriod INTEGER` default 14; `rsiOverbought DECIMAL` default 78; `rsiOversold DECIMAL` default 22.
- `divergenceLookbackBars INTEGER` default 20.
- `reversalPattern ENUM` {`ENGULFING`,`PINBAR`,`INSIDEBARBREAK`,`ANY`}.
- `targetRR DECIMAL` default 3.0.

### Setup, Trigger, Invalidation

**Setup:**

- Strong prior move identified by extended distance from MAs and high volatility bucket.[^2]
- RSI extreme above/below thresholds; optional price/RSI divergence over `divergenceLookbackBars`.

**Trigger:**

- Selected reversal candle pattern at or near swing extreme.
- Optional `marketContext.reversalSignal` not `NONE` when that field is available.

**Invalidation:**

- Close beyond reversal candle extreme in original trend direction.

### Exit And Risk

- Stop: Just beyond reversal candle extreme plus ATR buffer.
- Target: Fixed `targetRR` (for example 3R) due to lower hit rate but higher payoff.
- Time stop: After 16 bars if no follow‑through.

### India‑Specific Notes

- Works best around power hour and after parabolic intraday moves, which are common in Indian indices following news flows.[^4][^3]

**SPI:** `TradeIntentStrategy`.[^2]

### SPI, Instruments, Timeframes

- Timeframes: `M15`, `H1`, `D`.
- Instruments: NIFTY, BANKNIFTY, top F&O stocks.

Key parameters:

- `patternSet MULTIENUM` from {`PINBAR`,`ENGULFING`,`INSIDEBARBREAK`…}.
- `levelType MULTIENUM` from {`PRIOR_DAY_HL`,`PRIOR_WEEK_HL`,`ROUND_NUMBER`,`VWAP_BAND`}.
- `maxDistanceFromLevelPct DECIMAL` default 0.2.

### Setup, Trigger, Invalidation

**Setup:**

- Detect structural levels from daily/weekly bars or intraday swings.[^2]

**Trigger:**

- When candle pattern from `patternSet` forms within `maxDistanceFromLevelPct` of a level in favorable regime (for example trend‑continuation or rejection of level).

**Invalidation:**

- Close beyond level by more than buffer.

### India‑Specific Notes

- Indian educational content heavily emphasizes such patterns at prior‑day high/low and big round numbers (for example 45000 on Bank Nifty). This strategy systematizes that practice.[^5][^10][^4]

## 10. India Bollinger + RSI Range Strategy

**Id:** `india-bollinger-rsi-range-v1`  
**SPI:** `TradeIntentStrategy`.

### SPI, Instruments, Timeframes

- Timeframes: `M5`, `M15`.
- Instruments: BANKNIFTY, NIFTY, liquid mid‑/large‑caps.

Key parameters:

- `bbPeriod INTEGER` default 20; `bbStdDev DECIMAL` default 2.0.
- `rsiPeriod INTEGER` default 14.
- `rsiOversold DECIMAL` default 30; `rsiOverbought DECIMAL` default 70.
- `midExit BOOLEAN` default true.

### Setup, Trigger, Invalidation

**Setup:**

- Regime: `RANGEBOUND` or low trend‑strength from MarketContext.

**Trigger:**

- LONG: price touches or closes below lower Bollinger band and RSI < `rsiOversold`.
- SHORT: mirror at upper band and RSI > `rsiOverbought`.[^13][^9][^4]

**Invalidation:**

- Two consecutive closes outside same band in trade direction (indicates potential trend day).

### Exit And Risk

- Primary target at middle band; optional extended target at opposite band with partial exits.
- Stop beyond band plus ATR cushion.

### India‑Specific Notes

- Many Indian intraday guides show Bollinger+RSI mean‑reversion on NIFTY/BANKNIFTY; this variant ensures regime and volatility awareness.[^9][^4]

## 12. India VWAP Reversion – Mean Reversion To VWAP

**Id:** `india-vwap-reversion-v1`  
**SPI:** `TradeIntentStrategy`.[^14][^15]

### SPI, Instruments, Timeframes

- Timeframes: `M5`.
- Instruments: Liquid F&O stocks and indices.

Key parameters (subset):

- `bandMultiplier DECIMAL` default 1.0 (VWAP ± 1× intraday standard deviation or ATR proxy).
- `maxDistanceFromVwapAtr DECIMAL` default 2.0.
- `maxHoldingBars INTEGER` default 15.

### Setup, Trigger, Invalidation

**Setup:**

- Compute session VWAP and an ATR‑based band around it.

**Trigger:**

- LONG: price trades below lower VWAP band by up to `maxDistanceFromVwapAtr * ATR` and then closes back inside band.
- SHORT: mirror above upper band.[^15][^16][^14]

**Invalidation:**

- Price accelerates further away from VWAP by more than `maxDistanceFromVwapAtr`, signaling potential trend day.

### Exit And Risk

- Target at VWAP re‑touch; optional scale‑out with continued mean‑reversion.
- Tight ATR stop due to occasional trend days.

### India‑Specific Notes

- VWAP reversion is particularly popular among Indian intraday traders; risk controls and trend filters are essential to prevent fading genuine trend days.[^17][^14]

## 16. Volume Profile India – Value Area Rotations

**Id:** `volume-profile-india-v1`  
**SPI:** `TradeIntentStrategy` (prototype).[^2]

### Idea

- Trade tests of prior‑session value area low/high (VAL/VAH) and point of control (POC) on BANKNIFTY/NIFTY, computed via an internal histogram until a dedicated volume‑profile context is available.[^4][^2]

### Practical Simplification

- Use a fixed number of price buckets over recent N bars to approximate a profile.
- LONG when price probes VAL from above and rejects back into value area; SHORT at VAH.

### India‑Specific Notes

- Popular among Indian intraday communities for BANKNIFTY 15‑minute charts; treat as experimental due to computation cost and absence of first‑class SPI support.[^4][^2]

## 18. India Option Premium Decay – Underlying Proxy Strategy

**Id:** `india-option-premium-decay-v1`  
**SPI:** `TradeIntentStrategy`.[^2]

### Idea

- Since SPI lacks options chain, model underlying behavior that corresponds to intraday short‑straddle/strangle strategies: enter when range‑bound regime detected, exit on underlying breaking pre‑defined ATR bands or at time‑of‑day cutoffs.[^21][^9][^8]

### Practical Approach

- LONG volatility proxy (no trade) in `STRONGTRENDHIGHVOLATILITY` regimes; otherwise, treat flat underlying inside ATR bands as profitable “premium decay” and measure realized range vs thresholds.

### India‑Specific Notes

- Reflects extremely popular intraday short‑vol styles (for example 9:20 NIFTY/BANKNIFTY straddles) without needing actual options data; used mainly for directional and regime evaluation.[^21][^8]

## 19. India Event De‑Risking – Meta Strategy

**Id:** `india-event-de-risking-v1`  
**SPI:** `TradeSignalStrategy` overlay.[^2]

### Idea

- Not a standalone entry generator; instead, uses configured lists of event dates (earnings, RBI policy, budget, major global events) and emits diagnostics or vetoes entries from other strategies on those days.[^22][^21][^2]

### Implementation

- Reads `occurredAt` from context, normalizes to `LocalDate`, checks against parameter list; if match, sets a “risk‑off” flag in diagnostics that other strategies can query or that evaluation can use for segmentation.

## 20. India Portfolio Risk 3‑5‑7 – Risk Overlay

**Id:** `india-portfolio-risk-3-5-7-v1`  
**SPI:** `TradeIntentStrategy` overlay.[^2]

### Idea

- Implement the per‑trade/per‑position/portfolio 3‑5‑7 risk rule as a gate in each strategy using `StrategyPortfolioState` and per‑instrument bookkeeping.[^2]

### Implementation Sketch

- Each candidate `ENTERLONG`/`ENTERSHORT` intent computes proposed open risk in R.
- Read portfolio‑level exposure metrics (and, when available, open‑risk fields); if proposed trade would breach per‑position or portfolio caps, refuse entry and add diagnostic message.

### India‑Specific Notes

- SEBI and broking‑house data show consistent losses among over‑levered intraday traders; systematic risk caps are a key differentiator for professional‑grade Indian algo systems.[^22][^21][^3]

## Conclusion And Implementation Notes

These 20 families provide a comprehensive, SPI‑compatible palette of Indian‑market strategies for AlgoTradeX backtests, anchored both in the platform’s own blueprints and in well‑documented intraday/swing practices on NSE indices and F&O stocks.[^5][^6][^14][^9][^13][^4][^1][^2]

A practical roadmap is to:

1. Implement and unit‑test the simpler trend, ORB, VWAP, RSI swing, and mean‑reversion strategies first.
2. Add price‑action, range, and momentum variants.
3. Treat volume‑profile, SMC, options proxies, and meta‑overlays as incremental layers once the core catalog is stable.

Each strategy should ship with fixture‑based tests using AlgoTradeX golden runs, plus robustness and Monte Carlo diagnostics to ensure replay‑safety and statistical robustness in Indian contexts.[^1][^2]
